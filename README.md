# Product App

A simple full-stack web application for managing products and customer orders.

## Features

- User Login
- Add and manage products
- Display product list
- Create orders
- Select product quantity
- Calculate total order price
- View orders
- Dashboard for order management

## Technologies Used

### Frontend
- React.js
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express.js
- REST API

### Database
- MySQL

### Tools
- VS Code
- Git
- GitHub
- Postman
